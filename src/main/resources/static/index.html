Assistente Empresarial - RAG B2B

O backend RAG Multi-Tenant está ativo e pronto para operar com o modelo local Ollama e armazenamento vetorial via pgvector / LangChain4j.

Como embutir o Widget no site de qualquer cliente:

Basta colar a tag de script abaixo antes do fechamento da tag </body> do site do cliente:

<script src="http://localhost:8080/widget.js" data-slug="slug-da-empresa"></script>

Endpoints Principais:

  • Upload de Documentos (RAG): POST /api/documentos/upload (Multipart Form)
  • Chat Público (Widget): POST /api/publico/chat/{slug}/mensagem
  • Configuração do Widget: GET /api/publico/chat/{slug}/config
  • Documentação Swagger: /swagger-ui/index.html
